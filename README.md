# React: Форма з валідацією (Formik + Yup)


## Короткий опис проекту

**`Form`** — форма реєстрації з трьома полями:
- **Ім'я** — обов'язкове, мінімум 2 символи.
- **Email** — обов'язковий, перевіряється формат електронної пошти.
- **Пароль** — обов'язковий, мінімум 6 символів.

Валідація виконується через Yup-схему, помилки показуються під відповідним полем
лише після того, як користувач залишив поле (`onBlur`) — стандартна поведінка Formik.
При успішній відправці дані форми зберігаються в локальному стані та відображаються
під формою (форма при цьому очищується).

## Встановлення та запуск

```bash
npm install
npm install formik yup
npm run dev
```

Відкрити посилання з терміналу, зазвичай `http://localhost:5173/`.



## Перевірка результату

1. Спробувати відправити порожню форму — під кожним полем з'явиться повідомлення
   про обов'язковість заповнення.
2. Ввести некоректний email (без "@") — з'явиться повідомлення про некоректний формат.
3. Ввести пароль коротше 6 символів — з'явиться відповідне повідомлення.
4. Заповнити всі поля коректно та натиснути "Відправити" — форма очиститься,
   під нею з'явиться блок з відправленими даними (ім'я та email).
